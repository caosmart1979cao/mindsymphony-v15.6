# 心智协奏系统™ v15.6 技能纯化版 - 部署指南

此目录包含“心智协奏系统™ v15.6”的最终部署文件。本系统架构遵循 Anthropic Skills 体系标准，将所有核心能力重构为标准化的“技能 (Skill)”。

## 架构理念

本系统采用双层架构：
1.  **宏观协奏层**: 由 `mindsymphony.config.yml` 定义。它作为“总谱”，编排多个技能协同工作以完成复杂任务。
2.  **微观执行层**: 由 `skills/` 目录构成。每个子目录都是一个独立的、代码驱动的、可复用的“技能”，作为“乐器”，负责执行具体的原子任务。

## 文件结构

- **`system_prompt.md`**: 系统的核心身份与世界观文件。**在启动AI客户端时，请将此文件内容加载为System Prompt。**

- **`mindsymphony.config.yml`**: 系统的“宏观协奏总谱”。用于注册 `skills` 并定义它们之间的“信息素”自动化工作流。

- **`protocols/`**: 存放系统宏观协奏层所依赖的核心协议标准。
    - `pheromone_protocol_v1.0.md`
    - `worker_unit_protocol_v1.0.md`

- **`skills/`**: 存放所有标准化的“技能 (Skills)”。
    - 每个子目录都是一个独立的、可复用的“技能包”。
    - 每个技能包的核心是 `SKILL.md`，它定义了技能的能力和使用方法。
    - `scripts/` 子目录（可选）存放该技能赖以执行任务的、可靠的、确定性的代码。
    - `examples/` 子目录（可选）提供技能的使用范例。

## 使用方式

1.  **加载文件系统**: 将整个目录加载到您的环境中 (Claude Code / Gemini CLI)。
2.  **设定身份**: 将 `system_prompt.md` 文件的全部内容，加载到您所使用客户端的 **System Prompt** 或等效的配置区域中。
3.  **下达指令**:
    - **宏观任务**: 向“蜂后” `[M-03]` 下达高层级战略目标。例如：“启动一次关于‘Rust学习路径’的深度研究，并生成一份可视化概念报告。”
    - **微观任务**: 直接调用特定的“技能”。例如：“使用 `learning-pathfinder` 技能，为我规划一条学习React的路径。”
