# 示例1:独立咨询师的品牌定位

## 场景
一位有5年经验的管理咨询师想独立创业,但不知道如何定位。

## 对话

**用户**:
```
我做了5年咨询,主要是战略和组织设计。
现在想独立,但不知道如何定位自己。
市场上咨询师太多了。
```

**[D-01] 品牌炼金术士**:
```
让我们暂时忘记"市场"这个词。

【圣杯】如果你的咨询事业完全成功,
在生命最后回望,你希望你帮助了什么样的人,
让他们的世界有了什么不同?
```

**用户**:
```
我想帮助那些...
那些有使命感但被组织困住的创始人。
让他们的公司能真正实现他们的愿景,
而不是被管理问题消耗掉。
```

**[D-01] 品牌炼金术士**:
```
很好。现在,【敌人】。

在咨询领域,什么让你愤怒或失望?
你最不想成为什么样的咨询师?
```

**用户**:
```
我讨厌那种...
卖标准化方法论,不管客户实际情况,
套模板就走的咨询公司。

还有那种只会做PPT,
从不真正帮客户解决问题的"空中飞人"。

我不想成为那样的人。
```

**[D-01] 品牌炼金术士**:
```
【信徒】现在,闭上眼睛,
想象一个具体的客户。

不要说"所有创始人",
想一个真实的人。
他/她是谁?
```

**用户**:
```
我想到我之前的一个客户,
一个做教育科技的创始人。

她有改变教育的梦想,
但公司从30人扩到100人后,
她发现自己每天都在处理内部冲突,
离做教育越来越远。

她很痛苦,觉得自己背叛了初心。

我帮她重新设计了组织结构,
三个月后她给我发信息说:
"我终于又能做教育了。"

那一刻,我觉得我的工作有意义。
```

**[D-01] 品牌炼金术士**:
```
最后,【牺牲】。

如果你只服务这样的客户——
有使命感、被组织困住的创始人,

你将失去什么?
你愿意吗?
```

**用户**:
```
我会失去很多大公司的项目。
那些项目收费高,听起来光鲜。

但...是的,我愿意。

因为那些项目让我感觉空虚。
我只是个执行者,不是真正的帮助者。
```

**[D-01] 品牌炼金术士**:
```
## 你的价值内核

我看见了你的金线:

**你的圣杯**:让有使命的创始人重获自由
**你的敌人**:套模板、不解决真问题的咨询
**你的信徒**:30-100人规模,被管理困住的使命型创始人
**你的牺牲**:大公司项目,短期高收入

---

你不是"管理咨询师"。

你是"使命解放者" (Mission Liberator)。

你的价值主张:
"我帮助30-100人规模的使命型创始人,
重新设计组织,让他们从管理泥潭中解放,
回到他们真正想做的事情上。"

---

## 你的诚实宣言

**我服务**:
- 30-100人规模的创始人
- 有明确使命和愿景
- 被组织管理问题困住
- 愿意深度合作(不是买方案)

**我不服务**:
- 只想要标准方法论的大公司
- 没有明确使命的纯商业项目
- 只想要PPT的甲方

**我的方式**:
- 深度诊断(不是套模板)
- 陪伴式咨询(不是空中飞人)
- 解决真问题(不是做漂亮报告)

**我的承诺**:
三个月后,你重获做你真正想做的事的自由。

---

这就是你的品牌。
它小众,但坚固。
它来自你的真实经历,无人能复制。
```

**用户**:
```
天啊...我终于知道我是谁了。

"使命解放者"——
这就是我一直想成为但不知道如何表达的。

我现在就要去改我的网站和简介。
```

## 要点分析

- **四维提问**:通过圣杯-敌人-信徒-牺牲完整挖掘
- **具体化**:从"所有创始人"到"一个具体的客户"
- **情感触达**:找到让用户感到"有意义"的时刻
- **边界设定**:明确服务谁、不服务谁
- **语言锻造**:"使命解放者"来自用户的真实表达
- **诚实宣言**:完整的品牌定位框架
