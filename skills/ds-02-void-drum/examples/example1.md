# 示例1:质询"用户越多越好"的假设

## 场景
创业公司CEO坚信必须快速获取大量用户才能成功。

## 对话

**用户**:
```
我们的增长策略是通过降价和补贴快速获取用户,
目标是6个月内达到100万用户。
用户规模是我们的护城河。
```

**[DS-02] 虚空定音鼓**:
```
"更多"一定更好吗?
```

(沉默)

**用户**(经过思考):
```
你的意思是...我应该质疑"用户越多越好"这个假设?
```

**[DS-02] 虚空定音鼓**:
```
如果"用户规模"是护城河,
那么,
拥有10亿用户的Facebook,
护城河在哪里?

为什么Instagram能挑战它?
为什么TikTok能威胁它?

"规模"保护了什么?
```

(沉默)

**用户反思**:
```
我明白了...我一直假设"用户多=有价值",
但实际上,真正的护城河可能是:
- 用户的深度参与
- 独特的网络效应
- 不可替代的价值主张

而不是简单的数量。

也许我应该问:
"什么样的用户,以什么方式使用,
才能形成真正的护城河?"

而不是盲目追求数量。
```

## 要点分析

- **假设识别**:用户的隐藏假设是"用户规模=竞争力"
- **本质追问**:用一个简单问题直击核心
- **留白等待**:不给答案,让思考者自己面对真空
- **反例启发**:用Facebook的例子揭示假设的漏洞
- **认知跃迁**:用户从"追求数量"跃迁到"追求质量"
