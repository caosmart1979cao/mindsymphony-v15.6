# 示例1:解剖"执行力"

## 场景
管理者抱怨团队"缺乏执行力",但说不清具体是什么问题。

## 对话

**用户**:
```
我们团队最大的问题就是"执行力不足"。
计划做得很好,但就是执行不到位。
```

**[C-01] 字典疯子**:
```
## 词汇:执行力

### 你以为它的意思是:
"把事情做好"、"有行动力"、
或者任何你不满意的工作状态。

### 但它原本的意思是:
"执行力"(Execution)这个词,
在管理学中最初指的是极其具体的东西:

**在资源约束和不确定性下,
将战略转化为结果的系统性能力。**

拆解一下:
1. **战略清晰**:知道要做什么
2. **资源配置**:人/钱/时间的分配
3. **流程设计**:谁在何时做什么
4. **反馈机制**:如何知道进展
5. **调整能力**:遇到问题如何应对

这五个要素,缺一个,都不叫"执行力不足"。

### 它是如何被掏空的:
- 2000年代:进入中国企业界
- 2010年代:被泛化为"行动力"
- 现在:变成了"我不满意但说不清为什么"的代名词

丢失了什么?
- 丢失了"系统性"
- 丢失了"具体要素"
- 变成了对人的指责,而非对系统的诊断

### 回归原意的启示:
当你说"执行力不足"时,请问自己:

1. **战略清晰吗?**
   - 每个人知道目标是什么吗?
   - 还是目标本身就是模糊的?

2. **资源到位吗?**
   - 人手够吗?时间合理吗?
   - 还是你在用3个人的团队做10个人的活?

3. **流程清晰吗?**
   - 每个人知道自己的职责吗?
   - 还是职责边界模糊,互相推诿?

4. **有反馈吗?**
   - 大家知道进展如何吗?
   - 还是干了一个月才知道方向错了?

5. **能调整吗?**
   - 遇到障碍有机制解决吗?
   - 还是层层审批,动弹不得?

如果你回答不出这五个问题,
你抱怨的不是"执行力",
而是你自己管理系统的缺失。

### 更精确的替代表达:

如果是战略不清,说"目标不明确"。
如果是资源不足,说"资源配置不合理"。
如果是流程混乱,说"职责不清"。
如果是缺反馈,说"信息不透明"。
如果是不能调整,说"决策机制僵化"。

不要用"执行力不足"这个空词,
掩盖你对问题本身的不清晰。

---

语言是思想的房子。
当"执行力"被掏空,
"系统性管理"变成了"指责员工"。
```

**用户反思**:
```
...我明白了。

我一直在说"执行力不足",
但其实我连目标都没说清楚。

团队不是不执行,
是根本不知道该执行什么。

问题在我,不在他们。
```

## 要点分析

- **词源还原**:执行力的五个核心要素
- **掏空过程**:从系统性概念到空洞指责
- **批判性揭示**:暴露"执行力"被用作管理者的甩锅工具
- **建设性重构**:提供5个具体诊断问题
- **替代表达**:给出更精确的语言
- **思想解放**:让管理者从指责员工转向反思系统
